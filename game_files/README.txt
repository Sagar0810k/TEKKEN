PLACE YOUR GAME FILES HERE
==========================

The Tekken Tag Tournament 2 PC port ships NO game data. Its installer builds
the game from YOUR OWN legally obtained copy of:

  1. Tekken Tag Tournament 2 (USA or Europe) - Xbox 360 retail DISC IMAGE
     -> put the .iso file in this folder (any filename is fine)

  2. Title Update 3 for the Xbox 360 version
     -> put the update file (or the whole update folder) in this folder

The operator dashboard (the laptop window) automatically detects files placed
here and shows what it found.

IMPORTANT - READ THIS
---------------------
* These files are copyrighted by Bandai Namco. They must come from a disc you
  own (dumped from your own Xbox 360 disc) - not from a download site.
* The port's installer validates the disc image itself: it will tell you if
  the version or region is wrong.
* Title Update 3 is normally stored on your own Xbox 360 console cache.
* The console system (this project) never downloads or redistributes game
  files, per project brief section 9.

Once the files are here, run the port's ttt2_setup.exe and point it at:
  - the disc image in this folder
  - the Title Update 3 file in this folder
